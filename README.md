# Contact Manager

Project developed for ISMT UC Laboratórios de Programação (2024/25).  
Manages contacts with create, edit, search, filter, and sort functionalities.

## Features
- Add, edit, remove contacts
- Search contacts by name
- Sort contacts ascending/descending
- Validate email and phone (+351XXXXXXXXX)
- Data storage in text file

## Technologies
- Java (Swing for GUI or console)
- Collections and Streams
- JUnit & Mockito for tests

## How to run
1. Navigate to `src/`
2. Compile all Java files:

```bash
javac *.java
